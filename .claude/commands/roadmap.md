# /roadmap — Status & Prioritas Fitur cari_untung

Tampilkan ringkasan status pengembangan app cari_untung (CuanFlow) berdasarkan kondisi kode saat ini dan roadmap yang sudah disepakati.

Lakukan hal berikut:

1. Baca `CLAUDE.md` di root project untuk context roadmap
2. Baca `lib/src/core/config/feature_config.dart` untuk daftar feature flags terkini
3. Lihat git log singkat: `!git log --oneline -10`

Lalu tampilkan dalam format ini:

## Fitur yang Sudah Ada
Daftar fitur yang sudah live berdasarkan feature_config.dart dan folder features/.

## Roadmap Aktif
Prioritas fitur berikutnya beserta status estimasi effort.

## Feature Flags
Tabel ringkas: fitur apa aktif di mode personal / store / production.

## Commit Terbaru
5 commit terakhir yang relevan dengan development.

Gunakan bahasa Indonesia. Jawab ringkas dan to the point.
